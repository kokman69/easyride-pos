# Easyride სალარო

მაღაზიის აპი: მარაგი ფოტოებით, გაყიდვები ფასდაკლებით, ქირაობა, კლიენტები და პირადობის ფოტოები, ანგარიში. მუშაობს 4 ენაზე და ტელეფონზე მოსახერხებელია.

- **საიტი:** GitHub Pages, ეს რეპოზიტორია
- **ბაზა და ფოტოები:** Supabase, პროექტი `easyride`
- **შესვლა:** ორი პაროლი, ადმინის და კონსულტანტის. უფლებებს ბაზა ამოწმებს (RLS).

## ფაილები

| ფაილი | რა არის |
|---|---|
| `index.html`, `style.css`, `app.js`, `i18n.js` | აპი |
| `config.js` | Supabase-ის მისამართი და საჯარო (anon) გასაღები |
| `schema.sql` | ბაზის სტრუქტურა და უსაფრთხოების წესები. თავიდან გაშვება უსაფრთხოა |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | ტელეფონზე „აპად“ დასამატებლად |

## მოვლა

- **პაროლის შეცვლა:** აპში შედი ადმინით და გახსენი **პარამეტრები → პაროლები**. თუ ადმინის პაროლი დაგავიწყდა, Supabase-ში გახსენი **Authentication → Users → admin@easyride.app** და შეცვალე.
- **ასლი:** თვეში ერთხელ Supabase-ის **Table Editor**-ში `sales`, `products`, `customers` და `rentals` ცხრილები გადმოწერე CSV-ად.
- **უფასო ლიმიტი:** Supabase-ის უფასო პროექტი 7 დღე უმოქმედობის შემდეგ ჩერდება. ყოველდღიური გამოყენებისას ეს არ ხდება.
- **service_role** გასაღები აქ არასოდეს ჩაწერო.

## ტელეფონზე დამატება

- **iPhone (Safari):** Share → Add to Home Screen
- **Android (Chrome):** ⋮ → Install app
